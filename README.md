# Fog Detection Helmet - Tinkercad Simulation

Smart helmet project to detect fog and alert rider for safety.

### Components Used in Tinkercad:
- Arduino Uno R3 - 1
- Red LED - 1
- Yellow LED - 1
- 220 Ω Resistor - 1
- 200 Ω Resistor - 1
- 10 kΩ Potentiometer - 1 (used to simulate fog level)
- Piezo Buzzer - 1 (for alert)

### How it Works:
- The 10k Potentiometer simulates fog density.
- When the potentiometer value crosses threshold (fog detected):
    - Red & Yellow LEDs turn ON as warning
    - Piezo buzzer gives alert sound
- In real hardware, potentiometer would be replaced with Humidity / Fog Sensor (like DHT11).
